# moviSoSsou (APK)
1. Mets tous ces fichiers dans un dépôt GitHub (sans oublier le dossier .github).
2. Onglet Actions > "Build APK" > Run workflow (ou simplement un push).
3. Quand c'est vert, ouvre l'exécution > Artifacts > moviSoSsou-apk, télécharge et décompresse.
4. Installe app-debug.apk sur le téléphone (autoriser les sources inconnues).
